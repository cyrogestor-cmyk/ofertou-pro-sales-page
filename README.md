# OFERTOU PRO Sales Page

Olá! Este é o componente React + TypeScript + Tailwind CSS da Landing Page de Vendas do meu SaaS (OFERTOU PRO).

Stack utilizada: React 19, Tailwind CSS, Lucide Icons e Vite.

Quero que você faça uma revisão e melhoria visual/estética neste componente (design dos cards, microinterações, gradientes, efeitos visuais, copy e contraste).

⚠️ REGRAS TÉCNICAS OBRIGATÓRIAS (NÃO QUEBRAR):

1. Mantenha os mesmos nomes de props:

   - onSelectPlan(plan) -> Deve ser disparado nos botões dos planos para abrir o modal de checkout PIX.

   - onOpenLogin() -> Deve ser disparado no botão de Login.

   - onBack() -> Deve ser preservado para o botão de "Voltar ao Painel".

   - apiBase -> Utilizado para carregar os planos.

2. Mantenha a compatibilidade com ícones do 'lucide-react'.

3. As imagens reais dos mockups de WhatsApp ficam em:

   - '/mockups/wa_meli_real.png'

   - '/mockups/wa_shopee_real.png'

4. Preserve o ID dos 5 planos: 'starter', 'creator', 'elite', 'business' e 'empire'.

5. Entregue o código completo atualizado do arquivo 'SalesPageView.tsx' pronto para substituir no projeto.
